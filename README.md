## איך מתחילים
1. פותחים ריפו חדש ב-GitHub, למשל `MITAR-TWIN-GH`, ובוחרים פרויקט Supabase.
2. מעתיקים את כל תוכן החבילה לשורש הריפו.
3. פותחים סשן Claude Code על הריפו ומדביקים את הפרומפט מ-`PROMPT.md`.

## לפני הבנייה: ארבע בדיקות שלך
1. **`docs/RULES.md`:** האם הנוסחאות נכונות? שימי לב במיוחד לגודל כיתה 30, שהוא הנחה.
2. **מתחם 7:** יח"ד 7,500. לא ברור מההוראות אם זה ערך תוספת או סה"כ.
3. **סטטוס תכנית 603-0972307:** בפרק 4 במסמך המדיניות היא מוגדרת "אושרה 2026", ובטבלת הסקירה "דיון בהתנגדויות".
4. **גישה:** הוגדרה פנימית בלבד, בניגוד לברירת המחדל של קריאה ציבורית.

## בדיקת נתונים שבוצעה
- **סכום יעדי שבעת מתחמי המגורים הוא בדיוק 350,000.** כך הוא תואם ליעד העירוני בסעיף 6.3.
- **מנוע הכללים הורץ על שלוש תכניות הבדיקה.** נמצא ותוקן באג אחד בקריאת שורת רח"ק.
